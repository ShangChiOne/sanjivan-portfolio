1   What You Need (Prerequisites)

Before you start, make sure you have the following:

SoftwareVersionWhat it's for
Java JDK17 or newerRuns the application
GlassFish Server7.x (Jakarta EE 10)Application server
MySQL Server8.xDatabase
MySQL Connector/J8.x or 9.xLets GlassFish talk to MySQL
Apache Maven3.8+Builds the project
Quick version check: Open Command Prompt and run these to confirm everything is installed:

java -version    mvn -version

2   Install the Software

A Java JDK 17

  1. Download JDK 17 (or newer) from Oracle or Adoptium (search "JDK 17 download").
  2. Run the installer and follow the prompts.
  3. After install, open Command Prompt and type java -version — you should see a version number.

B Apache Maven

  1. Download the Binary zip from maven.apache.org.
  2. Extract it (e.g., to C:\maven).
  3. Add C:\maven\bin to your system's PATH environment variable.
  4. Open a new Command Prompt and type mvn -version to confirm.

C MySQL Server 8

  1. Download MySQL Installer from mysql.com.
  2. Run the installer — choose Developer Default or at minimum just MySQL Server.
  3. During setup, set a root password — remember this, you will need it later.
  4. Leave the port as the default: 3306.

D GlassFish 7

  1. Go to glassfish.org and download GlassFish 7.x (the zip file).
  2. Extract it anywhere you like, e.g., C:\glassfish7.
  3. You do NOT need to run an installer — just extract and it's ready.

E MySQL Connector/J

  1. Go to dev.mysql.com/downloads/connector/j/ and download the Platform Independent zip.
  2. Extract it — you only need the .jar file inside (e.g., mysql-connector-j-8.x.x.jar).
  3. Copy that .jar file into:
    C:\glassfish7\glassfish\domains\domain1\lib\
    (Create the lib folder if it does not exist.)

3   Set Up the Database

1 Open MySQL Command Line

Open Command Prompt and connect to MySQL:

mysql -u root -p

Enter your root password when prompted.

2 Run the Schema Script

Navigate to the project's database folder, then run:

source C:/path/to/CourseRecoverySystem/database/crs_schema.sql
Replace C:/path/to/ with the actual path where you placed the project.
Use forward slashes ( / ) even on Windows inside the MySQL prompt.

This will create the database crs_db and all tables, and insert default accounts and sample data.

3 Run the Enrolments Seed (Optional)

To load sample student grades for testing:

source C:/path/to/CourseRecoverySystem/database/enrollments_seed.sql

4 Verify

USE crs_db;
SHOW TABLES;

You should see tables like users, students, courses, recovery_plans, etc.

4   Configure GlassFish

1 Start GlassFish

Open Command Prompt and run:

C:\glassfish7\bin\asadmin start-domain

Wait until you see: "Command start-domain executed successfully."

2 Open the Admin Console

Open your browser and go to:

http://localhost:4848

Log in with username admin and leave the password blank (default), or use whatever you set during GlassFish setup.

3 Create a JDBC Connection Pool

  1. In the left panel, go to: Resources → JDBC → Connection Pools
  2. Click New
  3. Fill in:
    FieldValue
    Pool NameCRSPool
    Resource Typejavax.sql.DataSource
    Database Driver VendorMySql
  4. Click Next
  5. Scroll down to Additional Properties and add these properties:
    NameValue
    urljdbc:mysql://localhost:3306/crs_db
    userroot
    passwordyour MySQL root password
    useSSLfalse
    allowPublicKeyRetrievaltrue
  6. Click Finish
  7. Click on CRSPool → click Ping to test — you should see "Ping Succeeded"
Ping failed? Make sure MySQL is running and the mysql-connector-j jar is in the lib folder. Restart GlassFish and try again.

4 Create a JDBC Resource

  1. Go to: Resources → JDBC → JDBC Resources
  2. Click New
  3. Fill in:
    FieldValue
    JNDI Namejdbc/CRSDS
    Pool NameCRSPool
  4. Click OK

5   Build & Deploy the Application

1 Build the Project

Open Command Prompt, navigate to the project root folder (where pom.xml is), and run:

cd C:\path\to\CourseRecoverySystem
mvn clean package

This will compile the code and produce the EAR file. Wait until you see BUILD SUCCESS.

2 Find the EAR File

After a successful build, the EAR file is located at:

CourseRecoverySystem\CRS-ear\target\CRS-ear-1.0.ear

3 Deploy to GlassFish

You have two options:

Option A — Drag & Drop (easiest):

Copy the CRS-ear-1.0.ear file into:

C:\glassfish7\glassfish\domains\domain1\autodeploy\

GlassFish will automatically detect and deploy it. Wait about 10–15 seconds.

Option B — Admin Console:

  1. Go to http://localhost:4848
  2. Left panel → Applications
  3. Click Deploy
  4. Click Choose File → select CRS-ear-1.0.ear
  5. Click OK
Deployed successfully? You should see CRS-ear listed under Applications with status Enabled.

7   Troubleshooting

ProblemFix
Page not found at localhost:8080/CRS Make sure GlassFish is running and the EAR is deployed. Check localhost:4848 → Applications.
Ping failed on CRSPool Check MySQL is running. Confirm the mysql-connector-j jar is in domain1/lib/. Restart GlassFish.
BUILD FAILURE during mvn package Make sure JDK 17+ is installed and JAVA_HOME is set. Run java -version to verify.
Login fails with correct password Make sure crs_schema.sql was run successfully and the users table has records.
GlassFish won't start — port in use Another program may be using port 8080 or 4848. Stop it, or change GlassFish's HTTP port in the Admin Console.
Database connection error in app Verify the JNDI name is exactly jdbc/CRSDS and the pool name is CRSPool.

To stop GlassFish when you're done:
C:\glassfish7\bin\asadmin stop-domain
